# 🧵 متجر الفضائل - نظام البوتات المتكامل

نظام آلي متكامل لمتجر خياطة يدوية يعمل عبر Telegram، لتسهيل إدارة الطلبات وعرض المنتجات.

---

## 📋 متطلبات التشغيل

1. **برنامج Python** مثبت على الجهاز (الإصدار 3.10 أو أحدث).
2. **مكتبات بايثون** (سيتم تثبيتها في الخطوات التالية).

---

## 🚀 خطوات التشغيل لأول مرة

1. **تثبيت المكتبات:**
   افتح موجه الأوامر (Terminal) في مجلد المشروع واكتب:
   ```bash
   pip install -r requirements.txt
(إذا لم يكن هناك ملف requirements.txt، استخدم: pip install python-telegram-bot python-dotenv)

إعداد الملفات السرية:

انسخ ملف .env.example وسمّه .env.

افتحه واملأ التوكنات ومعرفات القنوات والمجموعات (ستجدها في BotFather وتطبيق Telegram).

تشغيل بوت الزبونات:
افتح نافذة Terminal واكتب:

bash
python bot.py
تشغيل بوت الإدارة (في نافذة Terminal أخرى):
افتح نافذة جديدة واكتب:

bash
python admin_bot.py
🤖 كيفية الاستخدام
1. بوت الإدارة (لصاحبة المتجر)
افتح بوت الإدارة في Telegram.

أرسل الأمر /add لإضافة منتج جديد.

اتبع الخطوات: (اختيار القسم ➡️ صورة ➡️ اسم ➡️ سعر ➡️ الخصائص ➡️ وصف).

سينشر البوت المنتج تلقائياً في القناة مع رابط الطلب.

2. بوت الزبونات (للزبونات)
الزبونة تتصفح القناة، وتضغط على رابط "اطلبي الآن" تحت أي منشور.

أو تفتح البوت مباشرة وترسل /start لتصفح الأقسام.

عند الطلب، تملأ الاستمارة (الاسم، الهاتف، العنوان).

يصل إشعار فوري إلى مجموعة الإدارة (لديك) باسم المنتج وتفاصيل الزبونة.

📂 هيكل الملفات
bot.py: بوت الزبونات.

admin_bot.py: بوت الإدارة.

products.json: قاعدة البيانات (المنتجات والأقسام).

.env: التوكنات السرية (لا تشاركه أبداً).

.env.example: قالب للإعدادات.

⚠️ ملاحظة أمنية هامة
لا تشارك ملف .env مع أي شخص. يحتوي على مفاتيح التحكم في البوتات.
