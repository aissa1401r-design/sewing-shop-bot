# 🧵 متجر الفضائل - دليل التشغيل والاستخدام

مرحباً بك في نظام إدارة متجر الفضائل! 🌸
هذا النظام يتكون من بوتين يعملان معاً لتسهيل إدارة متجركِ:
1. **بوت الإدارة:** لإضافة المنتجات، تعديلها، وحذفها.
2. **بوت الزبونات:** لاستقبال الطلبات من الزبونات.

---

## ⚙️ أولاً: كيفية التشغيل (للمرة الأولى فقط)

### 1. تثبيت المتطلبات
افتح موجه الأوامر (Terminal) في مجلد المشروع واكتب:
```bash
pip install -r requirements.txt

2. تشغيل البوتات
يجب تشغيل البوتين معاً في نفس الوقت (في نافذتين مختلفتين):

النافذة الأولى: python bot.py (لبوت الزبونات).

النافذة الثانية: python admin_bot.py (لبوت الإدارة).

(اتركي النافذتين مفتوحتين دائماً أثناء العمل).

📱 ثانياً: استخدام بوت الإدارة (لصاحبة المتجر)
افتحي بوت الإدارة في التليجرام، وأرسلي /start. ستظهر لكِ لوحة تحكم بأزرار ثابتة.

➕ إضافة منتج جديد
اضغطي على زر "➕ إضافة منتج".

اختاري القسم (جلابيب، عطور، إلخ).

أرسلي صورة المنتج.

اكتبي اسم المنتج.

اكتبي السعر (أرقام فقط).

اكتبي الألوان أو المقاسات (افصلي بينها بفاصلة أو نقطة، مثال: أحمر، أزرق).

اكتبي وصفاً قصيراً.
النتيجة: سيتم نشر المنتج تلقائياً في القناة مع رابط طلب ذكي!

✏️ تعديل منتج
اضغطي على زر "✏️ تعديل منتج".

أرسلي رقم (ID) المنتج (يمكنك معرفته من زر "📦 عرض المنتجات").

اختاري ماذا تريدين تعديله (السعر، الاسم، الوصف).

اكتبي القيمة الجديدة.
النتيجة: سيتم تحديث المنشور في القناة تلقائياً!

🗑️ حذف منتج
اضغطي على زر "🗑️ حذف منتج".

أرسلي رقم المنتج.

أكدي الحذف.
(ملاحظة: سيتم حذف المنتج من البوت، لكن المنشور في القناة سيبقى، يمكنك حذفه يدوياً).

📊 الإحصائيات
اضغطي على "📊 الإحصائيات" لرؤية عدد المنتجات في كل قسم، وعدد الطلبات التي وصلت.

🛍️ ثالثاً: كيف تصل الطلبات؟
عندما تطلب زبونة منتجاً:

تفتح رابط المنتج من القناة.

تختار اللون والمقاس.

تملأ بياناتها (الاسم، الهاتف، العنوان).

يصل إشعار فوري إلى مجموعة الإدارة (التي أضفتِ فيها بوت الزبونات).

تُحفظ كل الطلبات في ملف orders.json (لمراجعتها لاحقاً).

⚠️ ملاحظات هامة
لا تشاركي ملف .env مع أي شخص (يحتوي على كلمات مرور البوتات).

إذا توقف البوت، تأكدي من أن الإنترنت يعمل، وأن النوافذ مفتوحة.

إذا واجهتِ خطأ، أرسلي صورة للشاشة للمبرمج.
